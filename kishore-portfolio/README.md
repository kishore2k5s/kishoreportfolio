# Kishore S — Portfolio

A responsive interactive portfolio for Kishore S.

## Features
- Responsive mobile/desktop design
- Dark/light mode
- Animated scroll reveal
- Interactive project detail modals
- Scroll progress indicator
- Mobile navigation
- AWS / cybersecurity / cloud themed terminal hero
- LinkedIn, email and AWS Credly links
- No build tools or frameworks required

## Run locally
Open `index.html` in a browser.

## Publish on GitHub Pages
1. Create a GitHub repository, for example `portfolio`.
2. Upload `index.html`, `style.css`, and `script.js`.
3. Go to Settings → Pages.
4. Select Deploy from branch → main → /root.
5. Save. GitHub will provide your public website URL.

## Publish on Netlify
Drag the entire folder into Netlify's deploy area, or connect the GitHub repository.

## Publish on Vercel
Import the GitHub repository into Vercel. No build command is required.
